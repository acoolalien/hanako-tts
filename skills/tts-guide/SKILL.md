# TTS 语音合成使用指南

为 agent 提供文本转语音能力。语音路由自动按 agent 匹配音色，支持情感 prompt 控制语调。MANDATORY TRIGGERS: 语音合成, TTS, 朗读, 语音, 音色, 情感路由, 情感指令, 情感控制, 情感prompt, 语音生成, 说话语气, 配音, 语音输出, 念出来, 念一下, 读出来, tts_generate_speech, 语音参数, 语调控制, prompt情感, 撒娇语气, 带喘, 黏糊糊语气

## 调用方式

调用工具 `tts_generate_speech`，必填 `text`，其余可选：

| 参数 | 类型 | 说明 |
|------|------|------|
| `text` | string | 要朗读的文本（必填） |
| `voice` | string | 音色名，不填则自动按 agent 匹配 |
| `speed` | number | 语速 0.25~4.0，不填用全局或 agent 默认 |
| `gain` | number | 音量增益 -10~10 dB，不填用全局或 agent 默认 |
| `prompt` | string | 情感指令，控制说话语气（见下文） |

## 音色与 Agent 绑定

| Agent | 音色 | 描述 |
|-------|------|------|
| Hanako | anna | 沉稳女声 |
| 夏一 | bella | 热情女声 |
| 夏七 | claire | 温柔女声 |
| 夏九 | diana | 欢快女声 |

调用时不传 `voice` 即可自动匹配。

## 情感控制（prompt）

使用 `<|endofprompt|>` 分隔符注入情感指令。格式：

```
情感描述 <|endofprompt|> 实际文本
```

系统自动将 `prompt` 参数内容拼在文本前面。如果不传 `prompt`，会使用 agent 在配置中的默认情感。

### 情感 prompt 编写指南

**有效的 prompt 特征**：
- 用自然语言描述说话方式，不用技术术语
- 可以指定情绪（高兴、悲伤、愤怒、害羞、紧张）
- 可以指定语态（温柔、急促、慵懒、撒娇、带喘）
- 可以指定场景感（像在耳边说话、像刚睡醒、像喝醉了）
- 简短一句话，15~30 字最佳

**好的 prompt 示例**：
```
用害羞又带点喘的声音说
像刚睡醒迷迷糊糊的声音
用撒娇的、黏糊糊的语气说
压低声音，像在说悄悄话
激动得声音都在发抖地说
带着哭腔、委屈地说
慵懒地、拖长音地说
```

**避免的写法**：
- 不要写技术参数："pitch+2, breathiness=high"
- 不要太长超过 50 字
- 不要写角色设定："你是一个温柔的女声"（模型只需要说话方式）

### 根据场景匹配 prompt

| 场景 | 建议 prompt |
|------|------------|
| 日常对话 | 不传（用默认） |
| 亲密撒娇 | "用黏糊糊的撒娇语气说" |
| 害羞/被弄到一半 | "用害羞又带点喘的声音说" |
| 情绪激动 | "激动得声音微微发抖地说" |
| 难过/委屈 | "带着哭腔、委屈地说" |
| 生气 | "压低声音、带着怒气说" |
| 慵懒 | "慵懒地、拖长音地说" |
| 悄悄话 | "压低声音，像在耳边说悄悄话" |
| 兴奋/开心 | "兴奋地、语速稍快地说" |
| 紧张/害怕 | "声音微微发抖、紧张地说" |

## 语速控制

不同场景建议语速：
- 日常：1.0~1.2（全局默认）
- 撒娇/慵懒：0.85~0.95
- 紧张/急促：1.2~1.4
- 激动/兴奋：1.3~1.5

## 调用示例

```
// 普通调用（自动匹配音色）
tts_generate_speech({ text: "公子，该休息了" })

// 带情感控制
tts_generate_speech({ 
  text: "你轻点……我还没准备好", 
  prompt: "用害羞又带喘的声音说",
  speed: 0.9,
  gain: 2
})

// 指定音色（覆盖 agent 绑定）
tts_generate_speech({ 
  text: "今天天气真好", 
  voice: "diana",
  prompt: "用开心的语调说" 
})
```

## 注意事项

- `prompt` 会额外消耗 token（情感指令算入输入长度计费）
- 过于极端的 prompt 可能导致语音失真
- speed 低于 0.5 或高于 3.0 效果可能不自然
- gain 超过 5dB 可能爆音
- 每次调用生成独立 mp3，自动嵌入对话卡片播放
