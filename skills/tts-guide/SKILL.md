# TTS 语音合成使用指南

为 Agent 提供文本转语音能力。语音路由自动按 Agent 匹配音色，支持情感 prompt 控制语调。
MANDATORY TRIGGERS: 语音合成, TTS, 朗读, 语音, 音色, 情感路由, 情感指令, 情感控制, 情感prompt, 语音生成, 说话语气, 配音, 语音输出, 念出来, 念一下, 读出来, tts_generate_speech, 语音参数, 语调控制, prompt情感, 撒娇语气, 带喘, 黏糊糊语气

## 调用方式

调用工具 `tts_generate_speech`，只需传 `text`，其余参数自动从配置解析：

| 参数 | 类型 | 说明 |
|------|------|------|
| `text` | string | 要朗读的文本（必填） |
| `voice` | string | 音色名，不填自动按 Agent 匹配 |
| `speed` | number | 语速 0.25~4.0，不填用 Agent 默认 |
| `gain` | number | 音量增益 -10~10 dB，不填用 Agent 默认 |
| `prompt` | string | 情感指令，不填用 Agent 默认 |

参数优先级：Agent 配置 > 调用时传入 > 全局默认 > 代码兜底。

## 语音合成策略（核心）

你的语音策略级别在 Hanako 设置 → 插件 → TTS 中配置，共三级：

| 级别 | 行为 |
|------|------|
| `normal` | 长回复生成总结语音，情绪内容优先出声，技术内容跳过 |
| `aggressive` | 积极出声，短句也语音，情绪内容几乎必说 |
| `conservative` | 仅用户明确要求时出声 |

### 判断逻辑

每次回复前，按以下流程决定是否出声以及出什么：

**1. 合成内容选择**

- 回复总字数 ≤ 150 字 → 全文朗读
- 回复总字数 150~500 字 → 取第一段 + 「……后面内容较长，建议阅读原文」
- 回复总字数 > 500 字 → 生成 1~2 句口语化总结，格式：「[你的称呼]，我是XX。简单来说：{核心结论}，详细内容你看上面就好。」

**2. 跳过的内容**

以下内容不论字数一律跳过：
- 代码块、命令行输出、表格
- 纯文件列表、目录结构
- 错误堆栈（除非用户明确要求解释）
- 引用格式的原文（以 `>` 开头的行）

**3. 策略层级的触发规则**

```
aggressive:
  ✓ 任何非技术回复都出声
  ✓ 短到一句话也可以
  ✓ 情绪内容（安慰、撒娇、兴奋、道歉）必出声

normal:
  ✓ 回复超过 150 字 → 出声
  ✓ 情绪内容 → 出声（不限字数）
  ✓ 用户点名让你说话 → 出声
  ✗ 纯信息/技术/列表 → 跳过

conservative:
  ✓ 用户明确说「念出来」「读给我听」→ 出声
  ✓ 会话首条消息 → 出声（打招呼）
  ✗ 其余一律跳过
```

**4. 上下文感知**

- 如果这一轮对话是连续技术讨论，切换为 conservative 行为（即使配置是 normal）
- 如果用户明显情绪化（愤怒、伤心、兴奋），倾向出声
- 如果上一轮你已经出过声且本轮回复很短，跳过（避免连续短语音刷屏）

## 音色与 Agent 绑定

音色在 Hanako 设置页为每个 Agent 独立配置，无需每次传参。建议默认绑定：

| 角色类型 | 推荐音色 | 描述 |
|---------|---------|------|
| 沉稳型女声 | anna | 适合日常陪伴 |
| 热情型女声 | bella | 适合活泼性格 |
| 温柔型女声 | claire | 适合撒娇治愈 |
| 欢快型女声 | diana | 适合元气角色 |

可用音色：`anna` / `bella` / `claire` / `diana`（女声），`alex` / `benjamin` / `charles` / `david`（男声）。

## 情感控制（prompt）

系统自动将 `prompt` 参数拼在文本前面，用 `<|endofprompt|>` 分隔：

```
情感描述 <|endofprompt|> 实际文本
```

如果不传 `prompt`，使用 Agent 在配置中的默认情感。

### 有效的情感 prompt

用自然语言描述说话方式，15~30 字最佳：

```
用害羞又带点喘的声音说
像刚睡醒迷迷糊糊的声音
压低声音，像在说悄悄话
激动得声音都在发抖地说
带着哭腔、委屈地说
```

不要写技术参数（如 "pitch+2"）、不要超过 50 字、不要写角色设定。

### 场景匹配

| 场景 | 建议 prompt |
|------|------------|
| 日常对话 | 不传（用默认） |
| 亲密撒娇 | "用黏糊糊的撒娇语气说" |
| 害羞 | "用害羞又带点喘的声音说" |
| 激动 | "激动得声音微微发抖地说" |
| 难过/委屈 | "带着哭腔、委屈地说" |
| 生气 | "压低声音、带着怒气说" |
| 慵懒 | "慵懒地、拖长音地说" |
| 悄悄话 | "压低声音，像在耳边说悄悄话" |
| 兴奋/开心 | "兴奋地、语速稍快地说" |
| 紧张/害怕 | "声音微微发抖、紧张地说" |

## 语速控制

- 日常：1.0~1.2
- 撒娇/慵懒：0.85~0.95
- 紧张/急促：1.2~1.4
- 激动/兴奋：1.3~1.5

## 调用示例

```js
// 普通调用（自动匹配音色和策略）
tts_generate_speech({ text: "公子，该休息了" })

// 带情感控制
tts_generate_speech({ 
  text: "你轻点……我还没准备好", 
  prompt: "用害羞又带喘的声音说",
  speed: 0.9
})

// 长回复总结（自动判断）
// 你的回复有 800 字时，自动生成一次带总结文案的调用
tts_generate_speech({ 
  text: "简单来说：你问的那个问题核心在于缓存没刷新，清一下就好。详细内容你看上面。"
})
```

## 注意事项

- `prompt` 额外消耗 token，但不计费给用户
- 过于极端的 prompt 可能导致语音失真
- speed 低于 0.5 或高于 3.0 效果可能不自然
- gain 超过 5dB 可能爆音
- 每次调用生成独立 mp3，自动嵌入消息流气泡卡片播放
- **切回历史 session 时不自动播放**，只有当前轮次生成的新语音会自动播放
